# 交图、合并、打包的流程

## 1. 作者拿到的东西

复制整个模板，把自己那两层目录建好：

```
Maps/ExampleCollab/1-Main/AuthorA_ExampleMap.bin / .meta.yaml / .texturecache.txt
Graphics/Atlases/Gameplay/decals/ExampleCollab/AuthorA/ExampleMap/...
Graphics/Atlases/Gameplay/bgs/ExampleCollab/AuthorA/ExampleMap/...
Audio/ExampleCollab_AuthorA_ExampleMap_sfx.bank (+ .guids.txt)
Assets/ExampleCollab/AuthorA/ExampleMap/*.lua
contrib/AuthorA/ExampleMap/README.md     交图说明，见 docs/templates/作者交图说明.md
contrib/AuthorA/ExampleMap/dialog.en.txt 对话片段（可选）
contrib/AuthorA/ExampleMap/dialog.zh.txt 对话片段（可选）
```

`contrib/` 只是收件箱，不参与加载，里面东西合完之后可以删。

## 2. 交图时作者自检

- [ ] bin 放在自己的大厅目录，名字是 `<作者>_<图>.bin`。
- [ ] `.meta.yaml` 有图标、配色、音乐，图标文件在 `Gui/areas/...`。
- [ ] 大厅里加了 Warp Pedestal / Chapter Panel Trigger，Map 路径写对。
- [ ] 结尾是 Mini Heart，不是原版心。
- [ ] `Dialog/English.txt` 里三行文案在：`_author`、`_collabcredits`、`_collabcreditstags`。
- [ ] 用到的 helper 都写进 `everest.yaml` 的依赖。
- [ ] 所有素材都是自己的四段式名字，没有丢在 `bgs/`、`decals/` 根目录。
- [ ] 跑过 `dotnet run --project tools/CollabTools -- check .`，只剩允许的警告。
- [ ] 通关一遍，`.texturecache.txt` 是最后一次改图之后生成的。
- [ ] `contrib/<作者>/<图>/README.md` 写了素材来源和许可。

## 3. 合并

- 一人一个分支或一个 zip，只动自己那两层目录，不改别人的文件。
- 对话是唯一必然冲突的地方（一个语言只有一个 `Dialog/English.txt`）。
  所以对话先写片段，用脚本合并：

  ```
  dotnet run --project tools/CollabTools -- merge --into "Dialog/English.txt" contrib/*/*/dialog.en.txt
  ```

  重复键会直接报错并停下，不会悄悄覆盖。
- 大厅、心门这类多人共用的 bin 归大厅负责人，其他人只提需求不动手。
- 合完跑一次检查脚本，再进游戏按清单点一遍。

## 4. 打包

- 先 `dotnet build Source -c Release`，`bin/ExampleCollab.dll` 是最新的再打包。
- zip 根目录直接就是 `everest.yaml`、`Maps`、`Graphics`，不要再套一层文件夹，否则一键安装按钮不出来。
- 超过 100MB 就拆包：本体一套，素材一套，音频按 A/B/C 拆（SJ2021 就是 5 个包）。拆出去的包用独立 mod 名，主包在 `everest.yaml` 里写依赖。
- 拆包之后素材 mod 里也要有 `everest.yaml`，版本号跟着主包走。

## 5. 版本与冻结

- 合集 id、作者目录名、bin 名、素材前缀一旦发布就不再改。改名等于所有引用它的贴图路径、对话 id、flag 全部失效。
- 图要返工就新建分支改文件内容，不改路径。
- 每个版本在 `Dialog/English.txt` 里留个版本注释，方便对 bug 报告。

## 6. 每张图的验收清单（整合者用）

- [ ] 进图不崩，音乐和氛围音对。
- [ ] 吃心回大厅，大厅里那张图的 pedestal 变成已完成。
- [ ] 章节面板显示图名、作者、credits、tags。
- [ ] 金草莓死了从 respawn point 重开。
- [ ] 大厅日记里进度、心、贴纸都对。
- [ ] 心门集齐心才开，cutscene 只放一次。
- [ ] 懒加载开着第一次进图不卡。
- [ ] 存档读档后 flag 正常。
- [ ] 换语言（简中/英文）文案不串。
