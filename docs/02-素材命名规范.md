# 素材命名规范

一句话：**能出合集的东西都写全前缀**。
名字 = `<作者>_<地图>_<作用>_<名字>`，出场的四个字段都别省，这样文件被单独拷出来也认得出是谁的。

## 1. 字符规则

- 只用 ASCII：`A-Z a-z 0-9 _`。
- 空格、横杠、斜杠、加号、点号、中文、emoji 一律不进文件名；要分隔用下划线。
- 作者名在大合照里**注册一次**，之后全项目统一大小写（`Kelsey` 不能一半写成 `kelsey`）。Everest 的路径是大小写敏感的，Windows 上不报错、Mac 和 Linux 上直接找不到。
- 目录和文件同名同大小写，`Maps/.../AuthorA_ExampleMap.bin` 对应 `Graphics/.../AuthorA/ExampleMap/`，别一边 `ExampleMap` 一边 `examplemap`。

## 2. 四段式

```
AuthorA_ExampleMap_decal_bush.png
└─作者─┘ └─地图──┘ └作用┘ └名字┘
```

- **作者**：注册表里的那个写法。
- **地图**：这张图的短名，跟 bin 名一致。
- **作用**：闭集，见下一节。放在名字前面，这样一屏文件按作用排好，找「这张图的背景」不用翻。
- **名字**：这张图内部怎么叫都行，但同样不能有空格和中文。

变体加后缀：`_alt`、`_night`、`_open`。
帧号才用数字：`..._anim_fire00.png`、`..._anim_fire01.png`，连续、两位数、从 00 起。

## 3. 作用词表（闭集）

| 作用 | 放什么 | 例子 |
|---|---|---|
| `decal` | 静态装饰 | `AuthorA_ExampleMap_decal_bush.png` |
| `anim` | 逐帧装饰 | `AuthorA_ExampleMap_anim_fire00.png` |
| `bg` | 视差背景 | `AuthorA_ExampleMap_bg_clouds.png` |
| `fg` | 前景层 | `AuthorA_ExampleMap_fg_fog.png` |
| `tile` | 图块 / 自定义 tileset | `AuthorA_ExampleMap_tile_wood.png` |
| `obj` | 实体贴图 | `AuthorA_ExampleMap_obj_spring.png` |
| `npc` | 角色 / NPC 帧 | `AuthorA_ExampleMap_npc_theo_idle00.png` |
| `icon` | 章节图标 | `AuthorA_ExampleMap_icon.png` / `_icon_hover.png` |
| `skull` | 大厅骷髅 | `AuthorA_ExampleMap_skull.png` |
| `heart` | 日记心 / 心门心 | `AuthorA_ExampleMap_heart.png` |
| `sticker` | 日记贴纸 | `AuthorA_ExampleMap_sticker.png` |
| `map` | 大厅日记里的大地图 | `1-Main_map.png` |
| `ui` | 界面元素 | `AuthorA_ExampleMap_ui_panel.png` |
| `end` | 结算画面 | `AuthorA_ExampleMap_end_00.png` |
| `bgm` / `sfx` / `amb` | 音乐 / 音效 / 环境音 | 见下节 |
| `lua` | 脚本 | `AuthorA_ExampleMap_lua_intro.lua` |
| `readme` / `license` | 说明与授权 | `AuthorA_ExampleMap_readme.md` |

新增作用词要先改这份表再加文件，不然检查脚本会报。

## 4. 必须写全名的地方（全局唯一）

| 东西 | 规则 | 例子 |
|---|---|---|
| 音频 bank 文件 | `<合集>_<作者>_<图>_<bgm\|sfx>.bank`，`.guids.txt` 同名 | `ExampleCollab_AuthorA_ExampleMap_sfx.bank` |
| 音频事件 | `event:/<合集>_<作者>_<图>_<bgm\|sfx>/<名字>` | `event:/ExampleCollab_AuthorA_ExampleMap_bgm/main` |
| 对话 id | `<合集>_<大厅>_<作者>_<图>`，后缀 `_author` `_collabcredits` `_collabcreditstags` `_journal` | `ExampleCollab_1_Main_AuthorA_ExampleMap_author` |
| session flag | `<合集>_<作者>_<图>_<名字>` | `ExampleCollab_AuthorA_ExampleMap_rain` |
| Sprites.xml 节点 / 贴图 id | `<合集>_<作者>_<图>_<名字>` | `ExampleCollab_AuthorA_ExampleMap_orb` |
| 地图 bin | `<作者>_<图>.bin` | `AuthorA_ExampleMap.bin` |
| 大厅 bin | `<序号>-<大厅名>.bin` | `1-Main.bin` |

`CollabUtils2_MapCompleted_*` 是 CollabUtils2 自己的 flag，别占用这个前缀。
`objects/<helper名>/`、`Graphics/Atlases/Gui/CollabUtils2/` 这些是别人的命名空间，也别占。

## 5. 共用素材

确实要跨图共用（比如大厅和心门用同一套贴图）时：

- 放 `<合集>/_Shared/`，文件名 `<合集>_shared_<作用>_<名字>`。
- 在 `_Shared/README.md` 登记：谁建的、谁能改、哪些图在用。
- 引用方只读；改之前先在合集频道说一声。

## 6. 反例

| 反例 | 问题 |
|---|---|
| `bgs/Foreground.png` | 不在合集命名空间里，迟早盖到别人的贴图 |
| `Kelsey/` 和 `kelsey/` 并存 | 大小写不一致，换平台就找不到 |
| `lobby.bank`、`120_map.bank` | 名字没信息，撞车后不知道是谁的 |
| `flower2.png` | 结尾数字会被当成动画帧，单张图渲染出错 |
| `我的贴图.png` | 中文文件名，打包和工具链都可能翻车 |
| `SJ2021/1-Beginner/Asterisk.png` 这类路径 | 合集名写死在路径里，合集改名要全改；模板里用占位 id 统一替换 |

## 7. 自检

`python3 tools/check_assets.py .` 会检查：路径是否在合集命名空间、文件名是不是四段式、作用词是否合法、有没有空格/中文/结尾数字、bank 和 guids 是否配对、decal 是不是偶数尺寸。
它只是守门员，报错了按提示改，别改脚本放自己过去。
